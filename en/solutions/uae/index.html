Have another question? Contact us.
Does a mainland or free-zone setup change the software scope?

It can affect provider eligibility, invoice setup, required records and responsibility for data. The business should confirm the applicable rules with its legal, tax and compliance advisers before those items enter the build scope.

Can you integrate a UAE payment gateway?

Yes, after the provider accepts the merchant and supplies the required API access. The implementation should cover success, failure, refund, dispute and reconciliation records used by the operations team.

Can an existing CRM or accounting system remain in place?

Yes, if it has a suitable API or export method. We first define which system owns each record, how updates move between systems and what happens when a connection fails.
